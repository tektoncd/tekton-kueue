# Contributing to tekton-kueue

Thank you for contributing to tekton-kueue.

All contributors must follow the [Tekton Code of Conduct](code-of-conduct.md)
and [AI contribution policy](https://github.com/tektoncd/community/blob/main/ai-contribution-policy.md).
For community-wide contribution standards and processes, see the
[tektoncd/community repository](https://github.com/tektoncd/community).

See [DEVELOPMENT.md](DEVELOPMENT.md) to set up the project and run its build,
test, and lint checks. Include tests for behavior changes and update the README
when a change affects installation, configuration, or usage.
